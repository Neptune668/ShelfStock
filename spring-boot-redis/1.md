### 2、常用命令

| 命令                  | 功能                                       |
| --------------------- | ------------------------------------------ |
| `sadd key v [v...]`   | 添加一个或多个成员（已存在忽略）           |
| `smembers key`        | 取出所有成员（无序）                       |
| `sismember key v`     | 判断是否存在（1/0）                        |
| `scard key`           | 返回成员数量                               |
| `srem key v [v...]`   | 删除指定成员                               |
| `spop key [n]`        | 随机**弹出** n 个（取出即删除，抽奖消耗）  |
| `srandmember key [n]` | 随机取 n 个（**不删除**，抽奖预览）        |
| `smove src dst v`     | 把成员从 src 移动到 dst                    |
| `sinter k1 k2 ...`    | **交集**：多个集合共有的                   |
| `sunion k1 k2 ...`    | **并集**：合并去重                         |
| `sdiff k1 k2`         | **差集**：k1 有、k2 没有的（"我有你没有"） |

交集并集顺序无关，差集就有关系了
